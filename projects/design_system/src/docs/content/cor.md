# Cor

Não existe "azul 100" nem "cinza 500" aqui. Cada cor é nomeada pelo trabalho
que ela faz: ação, texto de apoio, contorno de campo. É esse nome que o
desenho e o código usam.

A diferença aparece na hora de escolher. Numa paleta organizada por tom, você
precisa decidir "qual azul?". Numa paleta organizada por papel, a resposta já
existe: se é a ação principal da tela, é a primária.

Toda cor existe nos dois temas. A primária vale `#3366cc` no claro e `#8ab4f8`
no escuro. O nome é o mesmo nos dois, e o valor muda sozinho.

## Regras

1. Use o nome da cor, nunca o valor. Um hexadecimal copiado à mão continua
   igual quando o tema vira, e a tela quebra no escuro.
2. Cor sozinha não indica estado. O item de menu selecionado muda o fundo, a
   cor do texto e o preenchimento do ícone, os três juntos.
3. Não existe fundo colorido decorativo. A secundária é o único fundo azul da
   interface, e serve ao botão secundário.
4. Vermelho é só erro e destruição. Não use para "atenção", nem para número
   negativo.
5. Marcador dentro de tabela é sempre neutro. O texto do marcador já diz o que
   ele é, e colorir por tipo de dado promete um significado que não existe.
